## Implemented working candidate

- Four private import tables, composite relational ownership, nullable replay links, active-run uniqueness, byte/row/event bounds and deletion triggers. No V2 IDs or user rows are rewritten. Empty import tables can downgrade; retained import data makes destructive downgrade refuse. Foreign-key target indexes protect removal/account-deletion paths.
- Pure versioned source adapters and strict request contracts; narrow Goodreads ISBN-wrapper support, checksum-valid ISBN-10 conversion, Unicode, exact dates or disclosed source-context warnings, private ratings/reviews/labels and original reported values. No external fetching, shared catalogue changes or preference inference. Unverified date-list syntax is retained, not guessed.
- One browser-driven workflow: sequential digest-checked batches, pinned header/mapping, sealed manifest, batched local work/edition evidence, complete target-group review, revision-bound confirmation, parent locking, transactional application/provenance/checkpoints, cancellation and seven-day logical expiry. Two transaction-scoped global processing slots; default 800 MiB maximum cannot raise an existing saved catalogue guard. Expired staging cleanup is bounded and cannot roll back forever merely because a new run fails capacity.
- Native Own/Want/notes/reactions/history win by default. Missing books are explicitly approved private entries. Existing source links, exact native Bookvane IDs and event markers prevent replay duplication/resurrection. Uncertain histories remain source context rather than manufactured reads. Changed accepted source content requires a new explicit decision; stale native versions return to review.
- **My Books → Bring Your Library** only: locally streamed CSV/TSV, safe column clarification, bounded pasted lists, official export-navigation links, paginated preview, explicit private/exception decisions, pause/resume, results and CSV template/export. A pinned, lazy-loaded MIT Papa Parse 5.7.0 is the only new runtime package. No worker, queue, storage service, hosting change or paid infrastructure.
- Accepted source context is collapsed in the existing private workspace with owner-only deletion; private labels filter My Books without becoming shared tags. Existing private JSON export includes accepted source context through explicit optional record types. CSV v1 is a limited portability format, not a full backup. Reversible `csv_escaped_fields` transport metadata protects spreadsheet formulas without losing original text. Row reports omit source text. Import commits invalidate previously cached shelf state.
- New import feature defaults **off** (`LIBRARY_IMPORT_ENABLED=false`); backend/schema and matching frontend must be reviewed together before a separately authorized rollout. No M6 authorization is inferred.
