# Reference covers

These are actual Standard Ebooks edition cover compositions, rendered from each publisher repository’s `images/cover.svg` and its linked `cover.jpg`. The prototype does not use invented jacket designs. They illustrate layout and are not a claim that Bookvane’s production covers or descriptions will be replaced.

- [Pride and Prejudice — Jane Austen](https://github.com/standardebooks/jane-austen_pride-and-prejudice/blob/master/images/cover.svg)
- [Frankenstein — Mary Shelley](https://github.com/standardebooks/mary-shelley_frankenstein/blob/master/images/cover.svg)
- [The Time Machine — H. G. Wells](https://github.com/standardebooks/h-g-wells_the-time-machine/blob/master/images/cover.svg)
- [The Great Gatsby — F. Scott Fitzgerald](https://github.com/standardebooks/f-scott-fitzgerald_the-great-gatsby/blob/master/images/cover.svg)
- [The Hound of the Baskervilles — Arthur Conan Doyle](https://github.com/standardebooks/arthur-conan-doyle_the-hound-of-the-baskervilles/blob/master/images/cover.svg)

The publisher’s [licence](https://github.com/standardebooks/jane-austen_pride-and-prejudice/blob/master/LICENSE.md) dedicates contributors’ work under CC0 and explains the public-domain status of source artwork/text. These references are for the design review. The final implementation should use existing catalogue cover URLs, with an intentional fallback when a cover is unavailable. The catalogue spans more than classics; the five public-domain examples are an asset-access limitation of this review, not a change in Bookvane’s audience.

Lora and Source Sans 3 are bundled with their SIL Open Font Licence files. The existing Bookvane logo is copied only into this isolated prototype and reduced for display; the original application asset is unchanged.
